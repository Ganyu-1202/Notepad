# Notepad
A simple and practical text editor, which supports functions such as finding replacements and font settings.

## 外观设置

- **视图 → 字体**：选择首要字体、备选字体，或直接调整“字号（磅）”。字号可以独立修改，预览与编辑区使用同一套字体应用逻辑。
- **视图 → 外观模式 → 浅色 / 深色**：切换 GTK 主题变体及编辑区配色。菜单、对话框和控件的具体样式由当前 GTK 主题提供；窗口标题栏由操作系统管理。
- **视图 → 背景设置**：支持跟随主题、纯色和图片。图片居中等比铺满编辑区域。纯色和图片背景均可通过滑动条或百分比输入框调整背景透明度（0% 完全不透明，100% 完全透明，显示主题底色）；两种控件数值同步，“跟随主题”下禁用。透明度不影响文字、光标和选区，点击确定后应用，取消则保留原设置。切换为纯色或跟随主题会清除图片。
- 自定义纯色背景会自动选择明暗文字以提高对比度。图片背景的文字颜色跟随外观模式，可调整背景透明度提高可读性。
- 外观设置在当前运行期间保留，暂不写入磁盘；重新打开软件使用默认设置。

## 行号、选中行与文件编码

- **视图 → 显示行号**：显示逻辑行号，滚动时同步；自动换行不产生额外行号。行号使用编辑器相同的字体、字重和字号，字体修改后自动更新行号栏宽度。
- **视图 → 框选中行**：为文本选区覆盖的每个逻辑行绘制框线；无选区时标记光标所在行。选区恰好结束于下一行行首时，不框入该下一行。两个视图开关默认关闭。
- 状态栏显示当前文档的实际读写编码，支持 UTF-8、UTF-8 BOM、带 BOM 的 UTF-16 LE/BE、UTF-32 LE/BE，以及 GB18030。打开时转换为 GTK 所需的 UTF-8；保存、另存为以及退出前保存均保留文档编码及 BOM。
- 无 BOM 的有效 UTF-8 按 UTF-8 处理；其他字节尝试以 GB18030 解码，并标注“推测”。无法可靠自动区分所有无标记编码（例如其他传统代码页、无 BOM 的 UTF-16），因此不承诺通用编码识别。保存成功后，编码已明确写入，清除“推测”标记。
- 文件解码失败或包含 NUL 字符时拒绝打开，保留原文档；新建文档重置为 UTF-8。外部修改磁盘文件不会改变当前内存文档的编码状态。

## 构建与验证

项目使用纯 C17 和 GTK 3，不引入 C++。需要 CMake、pkg-config 和 GTK 3 开发环境；Windows 下使用配套的 MSYS2 MinGW64 工具链，并将其 bin 目录加入 PATH。

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

默认启用 `BUILD_TESTING`；可通过 `-DBUILD_TESTING=OFF` 只构建主程序。GTK 测试需要图形会话，覆盖同字体仅修改字号、字号对话框确认、主题切换、纯色/图片切换、图片透明度与实际覆盖层合成、背景重置及资源释放；GTK 警告会使测试失败。

新增及修改的 C 代码使用 Allman 大括号风格。GTK/GLib/Pango 接口相关代码使用相应库类型，应用自身的布尔状态及通用逻辑使用 C 标准类型。
