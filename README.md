# Notepad
A simple and practical text editor, which supports functions such as finding replacements and font settings.

## 项目结构

```text
Notepad/
├── CMakeLists.txt
├── src/
│   ├── main.c                     # 程序入口
│   ├── core/                      # 应用状态、生命周期、文件与编码逻辑
│   │   ├── notepad.c / notepad.h
│   │   ├── file_operations.c / file_operations.h
│   │   └── document_encoding.c
│   ├── ui/                        # GTK 窗口、菜单、编辑器交互与设置界面
│   │   ├── ui.c / ui.h
│   │   ├── editor_decorations.c
│   │   ├── font_dialog.c
│   │   ├── font_picker.c / font_picker.h
│   │   └── tab_settings.c
│   ├── theme/                     # 深浅色、背景样式与图片绘制
│   │   └── appearance.c
│   └── common/                    # 通用消息与异常提示辅助
│       └── output_exception.c / output_exception.h
├── tests/                         # GTK 回归测试
│   └── appearance_test.c
├── notepad.png                    # 应用图标（保持原有位置）
└── README.md
```

这是按职责进行的目录归类，不是完全的前后端架构拆分：`core` 中现有文件操作仍包含 GTK 文件对话框及文本缓冲区调用，`common` 消息提示也依赖 GTK。本次不改变这些功能边界。头文件统一使用相对于 `src` 的路径（如 `core/notepad.h`、`ui/ui.h`），构建配置为主程序和测试共用一份模块源文件列表。现有构建目录无需移动，重新运行 CMake 即可更新路径。

## 外观设置

- **视图 → 字体**：在同一界面选择字体、字形、字号（磅）和备用字体，下方实时预览。无需再次打开嵌套字体选择窗口；字号可独立修改。备用字体选项直接可见，仅在主字体缺字时使用，字号随主字体同步。确定后应用，取消保留原设置。
- 字体设置窗口默认尺寸为 640 × 560，可调整大小；控件和弹出列表使用 GTK 原生主题，不额外模拟 Electron 的配色、圆角或阴影。
- 主字体和备用字体使用搜索式弹出列表：顶部搜索框按字体名称进行不区分大小写的包含匹配，下方列表固定 280 像素高（屏幕空间不足时由 GTK 调整弹出位置），始终显示可拖动的垂直滚动条；当前选项显示勾选标记。没有匹配项时显示提示。搜索和滚动不改变字体，点击结果后才选择；在搜索框按向下键可进入列表，回车选择首个结果，Esc 或点击外部关闭。字形保留独立下拉框。
- 搜索列表使用标准 GtkPopover 和固定行高树列表，不再依赖 GtkComboBox 内部弹窗的滚动事件补丁。
- 字体下拉列表使用固定宽度、按界面字体计算行高，避免显示窗口时逐一测量全部字体名称；较长名称省略显示。连续调整设置时合并 100ms 内的预览刷新，关闭窗口时取消待执行刷新。设置环境变量 `NOTEPAD_FONT_TIMING=1` 可输出字体枚举、窗口构建与显示、预览样式更新耗时。
- 字体列表排除 Sans / Serif / Monospace 等虚拟字体族，字形列表排除后端合成的样式，避免原 GTK 字体选择器预览不可加载的压缩、扩展等组合。实际字体可用性仍由本机安装字体及 Pango 后端决定。
- **视图 → 外观模式 → 浅色 / 深色**：切换 GTK 主题变体及编辑区配色。菜单、对话框和控件的具体样式由当前 GTK 主题提供；窗口标题栏由操作系统管理。
- **视图 → 背景设置**：支持跟随主题、纯色和图片。图片居中等比铺满编辑区域。纯色和图片背景均可通过滑动条或百分比输入框调整背景透明度（0% 完全不透明，100% 完全透明，显示主题底色）；两种控件数值同步，“跟随主题”下禁用。透明度不影响文字、光标和选区，点击确定后应用，取消则保留原设置。切换为纯色或跟随主题会清除图片。
- 自定义纯色背景会自动选择明暗文字以提高对比度。图片背景的文字颜色跟随外观模式，可调整背景透明度提高可读性。
- 外观设置在当前运行期间保留，暂不写入磁盘；重新打开软件使用默认设置。

## 制表符设置

- **编辑 → 制表符设置**：选择按 Tab 插入实际制表符（`\t`），或插入固定数量的空格（1–32，默认数量为 4）。默认使用制表符模式。
- 空格模式每次插入指定数量的空格，不是补齐至下一制表位；已有制表符不自动转换。有选区时以空格替换选区；插入支持撤销及重做。
- 仅接管编辑区无修饰键的 Tab，不改变设置对话框中的焦点导航和 Ctrl/Shift 等组合键行为。确定后应用、取消保留原设置，当前运行期间保留。

## 行号、选中行与文件编码

- **视图 → 显示行号**：显示逻辑行号，滚动时同步；自动换行不产生额外行号。行号使用编辑器相同的字体、字重和字号，字体修改后自动更新行号栏宽度。
- **视图 → 框选中行**：为文本选区覆盖的每个逻辑行绘制框线；无选区时标记光标所在行。选区恰好结束于下一行行首时，不框入该下一行。两个视图开关默认关闭。
- 状态栏显示当前文档的实际读写编码，支持 UTF-8、UTF-8 BOM、带 BOM 的 UTF-16 LE/BE、UTF-32 LE/BE，以及 GB18030。打开时转换为 GTK 所需的 UTF-8；保存、另存为以及退出前保存均保留文档编码及 BOM。
- 无 BOM 的有效 UTF-8 按 UTF-8 处理；其他字节尝试以 GB18030 解码，并标注“推测”。无法可靠自动区分所有无标记编码（例如其他传统代码页、无 BOM 的 UTF-16），因此不承诺通用编码识别。保存成功后，编码已明确写入，清除“推测”标记。
- 文件解码失败或包含 NUL 字符时拒绝打开，保留原文档；新建文档重置为 UTF-8。外部修改磁盘文件不会改变当前内存文档的编码状态。

## 构建与验证

项目使用纯 C17 和 GTK 3，不引入 C++。需要 CMake、pkg-config 和 GTK 3 开发环境；Windows 下使用配套的 MSYS2 MinGW64 工具链，并将其 bin 目录加入 PATH。

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

默认启用 `BUILD_TESTING`；可通过 `-DBUILD_TESTING=OFF` 只构建主程序。GTK 测试需要图形会话，覆盖同字体仅修改字号、字号对话框确认、主题切换、纯色/图片切换、图片透明度与实际覆盖层合成、背景重置及资源释放；GTK 警告会使测试失败。

新增及修改的 C 代码使用 Allman 大括号风格。GTK/GLib/Pango 接口相关代码使用相应库类型，应用自身的布尔状态及通用逻辑使用 C 标准类型。
